# UI 表示確認記録

- 実施日: 2026-07-10
- 対象: `http://127.0.0.1:13000/`
- ブラウザ: Playwright Firefox 151.0
- ビューポート: 1440 × 1000

## 確認内容

1. 初期設定画面で4席の操作種別・表示名・CPUレベル、全ルール設定、東一局・0本場・供託0本・各家25,000点を確認した。
2. 人間1人 + CPU3人で対戦を開始し、配牌、本人だけの手牌表示、CPU手牌の枚数表示、ドラ表示牌、残り山、河、鳴き面子、現在手番、合法アクションを確認した。
3. 人間が打牌した後、CPU3人が自動で打牌し、チー候補に対してパスすると本人の自摸・打牌手番へ戻ることを確認した。
4. CPU4人の東風戦を進行し、荒牌流局のテンパイ/ノーテン、ノーテン罰符、親継続、本場増加を確認した。
5. 結果確定前は卓上点数を変更せず、確定後に東一局1本場・供託1本、25,500 / 26,500 / 23,500 / 23,500点へ反映されることを確認した。
6. 初期画面・対局画面・結果ダイアログを目視し、要素の重なり、欠け、横方向のはみ出しがないことを確認した。

ブラウザコンソールのエラーは0件。開発モードの未使用フォントpreload警告2件のみで、対局処理に関する警告・例外はなかった。
