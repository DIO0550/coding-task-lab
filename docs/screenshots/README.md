# 対戦画面 表示確認スクリーンショット

`docs/spec-match-screen.md` に基づき、対戦画面を Playwright（Chromium, 1280×900〜1200）で実操作して取得した表示確認記録。
「対戦開始 → 配牌 → 打牌 → CPU自動進行 → 鳴き → CPUリーチ/ロン → 結果表示 → 点数反映 → 次局」の通しフローを実ブラウザで確認したもの。

| 画像 | 場面 | 確認内容 |
|---|---|---|
| [01-setup.png](./01-setup.png) | 対戦開始設定・初期表示 | 4席の操作種別(人間/CPU)・表示名・CPUレベル、ルール7項目(対戦形式/持ち点/返し点/喰いタン/後付け/赤ドラ/CPU自動和了)、初期表示(東一局・0本場・供託0本・各家25,000点・親: あなた) |
| [02-deal.png](./02-deal.png) | 対戦開始・配牌 | 人間の手牌14枚(親の第1ツモ、ツモ牌を離して表示)、CPU3家の伏せ牌13枚、残り山69枚、ドラ表示牌、手番バッジ |
| [03-discard-cpu-advance.png](./03-discard-cpu-advance.png) | 打牌 → CPU自動進行 | 人間が「中」を打牌して河へ反映、CPU3家が自動でツモ・打牌(各河が更新)、残り山65枚、手番が人間へ復帰 |
| [04-pon-offer.png](./04-pon-offer.png) | 鳴き応答フェーズ | CPUの打牌に対し人間へ「ポン」を提示、「宣言するか、パスを選んでください」。パスで進行(ロン>ポン/カン>チーの優先順位で解決) |
| [05-win-result.png](./05-win-result.png) | 和了結果表示 | CPU1がリーチ後に七対子でロン和了(放銃CPU2)。成立役(立直/七対子/ドラ2/赤ドラ)・6翻25符・12,000点(跳満・子ロン)・供託1本・和了者/放銃者の手牌公開。点数移動・輪荘・確定ボタン |
| [06-next-round.png](./06-next-round.png) | 点数反映 → 次局 | 確定で点数反映(CPU1: 37,000点/CPU2: 13,000点/供託0本復帰)、親がCPU1へ交代(輪荘)、風のローテーション、東二局・新しい牌山(残り山66枚・新ドラ表示)へ自動進行 |

取得手順は `docs/../rules/ui-verification.md` に準拠。ドメインロジック(点数計算・進行・CPU)は実物を用いており、和了点数は Part 1 の点数計算エンジン(`Scoring.evaluate`)の結果がそのまま画面に反映されている。
