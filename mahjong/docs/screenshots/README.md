# 対戦画面の表示確認ログ

[rules/ui-verification.md](../../../rules/ui-verification.md) に従い、playwright-cli で
実際の画面を操作しながら取得したスクリーンショットと確認結果。

## 環境

- 開発サーバー: `cd mahjong && pnpm run dev --port 13000`
- ブラウザ: `playwright-cli open --browser=chromium` / ビューポート 1440x1000
- 取得コマンド: `playwright-cli screenshot --filename=docs/screenshots/<name>.png`
  (パネル単体は `playwright-cli screenshot "getByRole('region', { name: '局結果' })" --filename=...`)
- 終局まで到達させる回は、`src/app/page.tsx` の `MatchScreen` に一時的に `autoAdvanceMs={0}` を
  渡して自動進行を最速にした(取得後に既定へ戻し済み。表示内容は間隔設定に依存しない)。

## 操作フローの確認結果

1. **対戦開始 → 配牌**: 各家13枚が配られ、親(人間)がツモして14枚になる。残り山が70→69枚へ減る。
2. **打牌 → CPUの自動進行**: 手牌の牌をクリックすると打牌され、下家・対面・上家が自動でツモ切り/打牌し、
   残り山が減って手番が戻る。
3. **鳴き**: 上家の打牌に対してチー/パスが提示され、チーを選ぶと鳴き面子が自分の欄に表示され、
   打牌者の河の該当牌が「鳴かれ」表示になる(`03-claim.png` の局面で確認)。
4. **リーチ**: CPUのリーチで持ち点が1,000点減り、供託が1本増え、宣言牌が横向きになる。
5. **和了**: ツモ・ロンとも自動的に結果パネルが開き、役・翻・符・点数移動・親継続を表示する。
6. **点数反映**: 確定で持ち点が結果どおりに増減し、次局(親の移動・本場・供託)へ進む。
7. **流局**: 山が尽きるとテンパイ判定とノーテン罰符を表示する。
8. **終局**: 東風戦の終了条件を満たすと最終順位を表示する。

レイアウト崩れ・要素の重なり・横スクロールは発生していない。
